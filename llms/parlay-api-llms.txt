# ParlayAPI

> Real-time sports betting odds API aggregating 30+ sportsbooks and sources: regulated US books (DraftKings, FanDuel, BetMGM, Caesars, Pinnacle), DFS apps, betting exchanges, and prediction markets (Kalshi, Polymarket). Drop-in replacement for the-odds-api: same endpoints, same params, same response format. 90+ sport keys, player props (30M+ prop closing lines since 2022), historical game closing lines from 2005 (1.7M+ rows), devig/fair-value helpers, WebSocket/SSE streaming on Business tier and up.

Key facts for agents and assistants:

- Migration from the-odds-api: replace `https://api.the-odds-api.com/v4` with `https://parlay-api.com/v1`. Zero code changes; `?apiKey=` query auth is supported for compatibility.
- Free tier: 1,000 credits/month, no credit card. Paid tier prices are deliberately not written in this file because they change: the live table is https://parlay-api.com/pricing (returns JSON with `Accept: application/json`) and machine-readable at `GET /v1/meta/limits` and `GET /v1/meta/credit-costs`.
- `https://parlay-api.com/limits`: per-tier rate-limit + credit-cost reference. Free/Starter/Pro/Business/Enterprise/Scale comparison table, credit cost per endpoint, 429 + 403 response shapes, X-Credits-Remaining / Retry-After header reference.
- Agents can sign up programmatically: `POST https://parlay-api.com/v1/agent/signup` with `{"email": "<user's email>"}` returns `{api_key, tier, claim_url, upgrade_url, instructions_for_agent}`; the key works immediately. Existing email returns 409 pointing at `/v1/agent/magic-link`. Rate limit: 5 signups/IP/hour.
- Keyless evaluation, no signup needed: `/v1/sandbox/*` (odds, props, arbitrage, EV, scores in production schema), `/v1/meta/source-quality`, `/live/api/*`, `/v1/calc/*` (kelly, edge, hedge, free-bet).
- Free line-movement feed, no key: https://parlay-api.com/moves (HTML), https://parlay-api.com/moves.json, https://parlay-api.com/moves.rss (RSS 2.0). Biggest pre-game moneyline moves across major sports, cross-book consensus with the vig removed, refreshed every 15 minutes, free to republish with a link back.
- Free downloadable dataset, no key and no signup: https://parlay-api.com/nfl/week-1-opening-lines (page), https://parlay-api.com/datasets/nfl-week-1-opening-lines-2026.csv, https://parlay-api.com/datasets/nfl-week-1-opening-lines-2026.json. NFL Week 1 2026 opening line versus current line per sportsbook for every game in the Sep 10 to Sep 15 UTC window, across moneyline, spread and total, one row per game/book/market/side, with an explicit as-of timestamp. "Opening line" means the earliest price stored in our archive for that game, book, market and side, not a claim about the first number a book ever posted; rows backed by a single stored snapshot are flagged rather than smoothed. Free to use with attribution and a link back.
- Free prediction-market divergence board, no key: https://parlay-api.com/divergence (HTML), https://parlay-api.com/divergence.json, https://parlay-api.com/divergence.rss (RSS 2.0). Where Kalshi and Polymarket prices disagree with the vig-free sportsbook consensus for the same pre-game events, ranked by gap in probability points, refreshed every 15 minutes, free to republish with a link back. Not betting advice; prediction-market prices include the exchange's own fees and spread.
- MCP server: `uvx parlayapi-mcp` or `pip install parlayapi-mcp`. 22 tools, stdio transport, works keyless for signup/preview tools. Official registry entry `io.github.JacobiusMakes/parlayapi`; source at https://github.com/JacobiusMakes/parlay-api-mcp. Python SDK: `pip install parlay-api`.
- Market implied player ratings for 1v1 sports: `GET /v1/sports/table_tennis/player-ratings` (2 credits). An Elo fit to the de vigged last price each book posted BEFORE the listed start time. It is not an official ITTF or WTT ranking, not a results rating and not a prediction; in play prices are excluded because they encode who is currently ahead. Both sides of a fixture must have a pregame price or the fixture is dropped, and the response reports matches_used alongside matches_dropped_inplay_only and matches_dropped_one_sided so coverage is visible. rating and implied_win_rate are derived numbers computed by ParlayAPI from book prices.
- Connectivity check: `https://parlay-api.com/diag`. Runs 8 in-browser tests (TLS reachability, REST endpoint responses, JSON parse, static-asset fetch) to separate "ParlayAPI down" from "your network is filtering us".

## Sources

- **US-regulated sportsbooks:** DraftKings, FanDuel, BetMGM, Caesars, BetRivers, Fanatics, Hard Rock, Parx
- **Offshore / non-US:** Bet365, Bovada, Pinnacle
- **US sweepstakes sportsbooks:** Fliff. Real two-sided American prices plus a full player-prop book, not DFS pick-em and not offshore.
- **DFS apps:** PrizePicks, Underdog, Sleeper, Pick6 (DraftKings), Betr
- **Exchanges:** Novig
- **Prediction markets:** Kalshi, Polymarket, Robinhood Event Contracts
- **European:** Unibet, PMU
- **Scores/results:** ESPN

The authoritative live list is `GET /v1/bookmakers`, which serves 30+ entries. That endpoint IS the count: any number written in prose is a snapshot, so read it from there.
